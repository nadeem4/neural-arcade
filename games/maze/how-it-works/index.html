How an explorer learns where the treasure is

An explorer stands in a grid and knows nothing. It gets a reward only when it reaches a treasure, and a small cost for every step. From that alone it works out the best way to walk. The trick is that the news of a reward travels backward, one step at a time.

5 min readTry it live

01

The world is a small grid

The explorer starts in the bottom-left corner and moves up, down, left or right. Walls block it. There is a small treasure close by and a big one far away. Every step costs a little, so wandering is not free.

One run from the start until the explorer reaches a treasure, or runs out of steps, is called an episode. It learns by playing many of them.

02

Value spreads backward

The explorer keeps a number for every tile: its value, how much reward it expects from there on. At first every value is zero. Then it stumbles onto a treasure, and the tile next to that treasure learns that it is worth something.

The next time, the tile one step further back learns from that tile, and so on. Each tile only ever looks one step ahead, but the news keeps travelling. Value spreads backward from the reward, one step at a time.

03

The discount decides which treasure

A reward far away is worth a little less than the same reward close by. The discount says how much less: at each step the explorer multiplies what is ahead by a number between 0 and 1. A low discount makes it short-sighted. A high one makes it patient.

On this map that choice flips the answer. The small treasure is near, the big one is far.

04

Exploring costs near a cliff

If the explorer only repeated its best-known move it would never find anything new. So some of the time it tries a random move instead. That is exploring, and it is how the first treasure gets found at all.

But exploring is not free. On this map the short way to the treasure runs beside a pit, and a random step to the side is a fall.

05

What it has and has not learned

  • It is a table, not a brain. The explorer keeps one number for each tile and move, and nudges it a little after every step. There is no network here, only a lookup.
  • It only knows this map. Change the walls and it has to start again.
  • The figures come from one recorded run (seed ), so they are the same on every visit.
