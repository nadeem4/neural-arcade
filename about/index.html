About Neural Arcade

Neural Arcade is a set of small browser games where a tiny neural network learns in front of you. Each game teaches exactly one machine learning idea, so the arcade works as a curriculum you can play.

Videos of an AI learning to drive can only be watched. Here you are part of the training loop: you set the fitness, the mutation rate, the track, the data or the reward, and you see what that does to the learning. The networks stay tiny, so every neuron and weight can be drawn live.

Failure is part of the lesson. Each game has a way to break learning on purpose, because seeing a brain overfit, drift or find a loophole teaches more than seeing it succeed. Built by Nadeem.
