1. Press Sweep a few times. Watch the glow spread out from the treasure.
  2. Lower the Discount and press Sweep x10. Only tiles near the treasure glow. Raise it and press Sweep x10 again: the glow reaches the start.
  3. Press Walk uphill. The robot steps to the brightest neighbour each time and reaches the treasure.

What you saw

  • Value spreads back from the treasure. The tile beside it is worth nearly the full prize, and each tile further back a little less.
  • The discount sets how far. Low, and only tiles near the treasure look valuable. High, and it reaches the start.
  • A high discount makes the start worth more. That is how the agent can tell which way to go from far away.

Key terms

TermIn this game
ValueThe return you can expect from a state, acting well.10 beside the treasure, 1.81 at the start.
DiscountHow far the value spreads back. See Lesson 3.Higher reaches further back toward the start.

In code: the same idea in Python

 
gamma = 0.9
route = [5, 6, 7, 8, 13, 18]
rewards = [-1, -1, -1, -1, -1, 10]

V, G = {}, 0
for state, reward in zip(reversed(route), reversed(rewards)):
    G = reward + gamma * G
    V[state] = round(G, 2)
print(V)

The same sum as the return, kept for every state on the route. The tile next to the treasure is worth 10; the start is worth 1.81.

The lesson: a state's value is the reward the agent can expect from there. It spreads back from the treasure, and the discount decides how far.
