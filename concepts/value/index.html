Concepts / Value

Value

A state's value is how much reward the agent can expect from there on, if it keeps following its policy.

    Value is the reward you can expect from here

    A state's value is a forecast: starting from this cell and playing well, how much reward will the agent collect? The cells leading to the treasure are worth a little less with every step back.

    Value spreads back from the treasure

    A cell next to the treasure is worth nearly the full prize. A cell one step further is worth a bit less, and so on. The numbers form a slope that always points toward the reward.

    The discount sets how far the slope reaches

    With a low discount the slope is short: only cells close to the treasure look valuable. With a high discount it reaches all the way back to the start, so the agent can tell which way to go from far away.

    The lesson: a state's value is the reward the agent can expect from there. It spreads back from the treasure, and the discount decides how far.
