Lesson 1: Agent and environment

Who decides what happens next in this room: the robot, or the room?

In this game: The robot is the agent and the room is the environment: all it gets back is where it is and a reward.

  1. Press the arrow buttons yourself. You are the agent: you pick the move, the room answers.
  2. Press Hand over to the AI. Now a program is the agent. Watch What the AI sees: only its position and the reward.
  3. Make one move right, then read What the AI sees. The agent chose; the room replied with a new position and a reward.

Agent and environment

The robot is the agent: the thing that decides. Everything else is the environment: the walls, the treasure, the pit.

They take turns. The agent picks one move. The environment answers with two things: where the agent now stands, and a number that says how that move went. Then the agent picks again. That turn-taking is the loop, and all of reinforcement learning happens inside it.

In code

state, info = env.reset()
done = False
while not done:
    action = agent.act(state)
    state, reward, terminated, truncated, info = env.step(action)
    done = terminated or truncated

env is the room and agent is the robot. Each pass through the loop is one turn.

The lesson: the agent controls one thing, its next move. Everything it learns, it learns from what the environment answers.
