Two sides of one loop

    Reinforcement learning splits the world in two. On one side is the agent, the thing that decides. On the other is the environment, everything the agent cannot decide: the walls, the treasure, the pit.

    The agent acts

    The agent picks one action, such as a step to the right. That is all it controls. It cannot move the treasure or change the walls.

    The environment answers

    The world replies with two things: where the agent now stands, and a reward, a number that says how that move went. Then the agent picks again.

    The lesson: the agent only ever sees what the environment tells it back. Learning is deciding better, using just those answers.
