Add the rewards you saw in step 2 by hand: that sum is one try's score. The pit ends a try, so a short try can be the worst one. The robot's try 1 scored -42 (32 steps at -1, then the pit at -10). After 200 tries it scores +5, the best this room allows: 5 steps at -1, then the treasure at +10.

Key terms

TermIn this game
RewardThe number the room sends back after a move.-1 for a step, +10 for the treasure, -10 for the pit.
Try (episode)One run from the start until it ends.The start tile to the treasure or the pit. Its score is the rewards added up.

In code: the same idea in Python

 
scores = []
for try_number in range(200):
    state, info = env.reset()
    score, done = 0, False
    while not done:
        action = agent.act(state)
        state, reward, terminated, truncated, info = env.step(action)
        agent.learn(reward)
        score += reward
        done = terminated or truncated
    scores.append(score)

Each pass through the outer loop is one try, and score is its tally. agent.learn is where the robot keeps what paid; later lessons open it up.

The lesson: Reinforcement learning is learning from rewards when nobody gives the answers.
