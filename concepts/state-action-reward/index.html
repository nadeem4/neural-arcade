Lesson 2: State, action, reward

Every step is three things: the state you are in, the action you take, the reward you get back.

In this game: The state is where the robot stands. The action is an arrow. The reward is the number the room hands back.

  1. Press an arrow once and read the Log. Each line is a state, an action and a reward.
  2. Walk next to the pit and try each move. Find the line where the reward is −10.
  3. Walk to the treasure and find the reward it pays. Compare it with an ordinary step.

What you saw

  • The middle is the state. Where the robot stands right now.
  • Each arrow is an action. One of the moves open from that state, with its reward beside it.
  • Most steps cost a little. The pit and the treasure are the big numbers.

Key terms

TermIn this game
StateWhere things stand right now.The robot's position in the room.
ActionOne choice open from that state.Up, down, left or right.
RewardA number for how that one step went.−1 a step, −10 the pit, +10 the treasure.

In code: the same idea in Python

 
state, info = env.reset()
done = False
while not done:
    action = agent.act(state)
    next_state, reward, terminated, truncated, info = env.step(action)
    print(state, action, reward)
    state = next_state
    done = terminated or truncated

One line is printed per turn: the state the agent was in, the action it took, and the reward that came back.

The lesson: a state offers actions, and every action comes with a reward. Learning is working out which actions are worth taking.
