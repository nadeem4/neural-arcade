State, action, reward

A state is where things stand now, an action is a move the agent can make, and a reward is the number the world hands back for that move.

    Three words, one step

    Every step of reinforcement learning is described with the same three words. Learn them once and every game here reads the same way.

    State

    The state is where things stand right now. In this grid it is just which cell the agent is on, so each cell has its own number.

    Action

    An action is one move the agent may make from that state. Here there are four: up, down, left and right.

    Reward

    For each action the world hands back a number. A treasure pays 10, a pit costs 10, and every ordinary step costs a little, so wandering is never free.

    The lesson: a state offers actions, and every action comes with a reward. Learning is working out which actions are worth taking.
