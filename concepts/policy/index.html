Lesson 4: Policy

A policy is the agent's rulebook: in each state, which action to take.

In this game: Put an arrow on every tile: that set of arrows is the policy.

  1. Press Go with the arrows as they are. They all point right, so see where the robot ends up.
  2. Click a tile to turn its arrow, then press Go. Try to lead the robot round the pit to the treasure.
  3. Press Let the AI fix it. It rewrites the arrows that led the robot wrong, then walks the robot.

A policy is a rulebook, one move per place

The agent does not plan from scratch every step. It carries a rulebook that says what to do in every state, and it just follows it. That rulebook is the policy.

One action per state

In this grid the policy is an arrow in every cell. Wherever the agent stands, it looks up that cell and takes the move the arrow shows.

Good and bad rulebooks

Some rulebooks go round in circles, some run straight into the pit, and some find the treasure. Learning is the search for a rulebook that earns a lot of reward.

In code

policy = {5: "right", 6: "right", 7: "right", 8: "down", 13: "down", 18: "right"}

state, info = env.reset()
done = False
while not done:
    action = policy[state]
    state, reward, terminated, truncated, info = env.step(action)
    done = terminated or truncated

The policy is a lookup: for the state the agent is in, which action to take. This one walks the shortest route to the treasure.

The lesson: a policy says which action to take in each state, and a better policy earns more reward. Reinforcement learning is the search for a good one.
