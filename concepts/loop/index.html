Lesson 2: The loop

The agent picks an action. The environment answers with a reward and a new situation. Then it repeats.

In this game: The robot is the agent. The room is the environment: its walls, pit and treasure.

  1. Press the arrow buttons yourself. You are the agent: you pick the move, the room answers.
  2. Press Hand over to the AI. Now a program is the agent. Watch What the AI sees: only its position and the reward.
  3. Make one move right, then read What the AI sees. The agent chose; the room replied with a new position and a reward.

What you saw

  • The agent picks an action. One of four arrows.
  • The room answers. A new position and a number for how it went.
  • Repeat. Until the treasure or the pit.

Key terms

TermIn this game
AgentThe one that decides. It controls only its next action.The robot.
EnvironmentEverything else. It decides what each action leads to.The room: its walls, pit and treasure.
The loopAct, get an answer, act again.A move, then a new position and a reward.

In code: the same idea in Python

 
state, info = env.reset()
done = False
while not done:
    action = agent.act(state)
    state, reward, terminated, truncated, info = env.step(action)
    done = terminated or truncated

env is the room and agent is the robot. Each pass through the loop is one turn.

The lesson: the agent controls one thing, its next move. Everything it learns, it learns from what the environment answers.
