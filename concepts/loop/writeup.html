One worked number

Turn 1: the agent sends Right. The room answers reward -1, now at x 1, y 1. Six turns like this reach the treasure: 5 x -1 + 10 = +5. Cut the answer and the same robot never learns where it is: it sends Right into the wall, 10 Steps, score -10.

Key terms

TermIn this game
AgentThe one that decides. It controls only its next action.The robot.
EnvironmentEverything else. It decides what each action leads to.The room: its walls, pit and treasure.
ActionOne move the agent sends to the environment.One of the four arrows.

In code: the same idea in Python

 
state, info = env.reset()
done = False
while not done:
    action = agent.act(state)
    state, reward, terminated, truncated, info = env.step(action)
    done = terminated or truncated

env is the room and agent is the robot. Each pass through the loop is one turn.

The lesson: Everything in reinforcement learning is this one loop.
