Lesson 9: When moves slip: the MDP

An action now has odds, so a value is an average over what might happen. States, actions, rewards and odds together are called an MDP.

In this game: The icy floor makes moves slip: 8 in 10 go as meant.

    What you saw

    • Each day is a state. Sunny, cloudy or rainy.
    • Tomorrow comes from odds. They depend only on today, not on last week.
    • The odds out of a state add up to 100%. The picture has states and odds only; the code below adds actions.

    Key terms

    TermIn this game
    Transition probabilityThe chance of each next state after an action.On ice, 8 in 10 moves go as meant.
    Markov propertyThe next state depends only on the present one.Only the tile you stand on matters.
    MDPStates, actions, rewards and transition probabilities, written down.The whole room as four lists.

    In code: the same idea in Python

     
    # P[state][action] = [(probability, next_state, reward, done), ...]
P = {
    18: {
        "right": [(0.8, 19, 10, True), (0.1, 13, -1, False), (0.1, 23, -1, False)],
        "up":    [(0.8, 13, -1, False), (0.1, 17, -1, False), (0.1, 19, 10, True)],
    },
}

for probability, next_state, reward, done in P[18]["right"]:
    print(probability, next_state, reward, done)

    On ice a move goes where you meant 8 times in 10 and slips sideways otherwise. This table, for every state and action, is the whole game written down.

    The lesson: an MDP writes the game down as states, moves, rewards and odds, and the next state depends only on the present one, not on how you got there.
