1. In step 1, send the robot down each route and read its total.
  2. In step 2, watch the chest and the coin shrink in the room.
  3. In step 3, drag the discount down until the robot picks the coin.

The return is everything still to come, added up

Each move costs 1 point. The coin pays 2, the chest pays 10. Add up every reward on a route and you get its return. The robot is not after the next reward; it is after the biggest return.

Coin: −1 + 2 = 1. Chest: −1 −1 −1 −1 −1 + 10 = 5. Counted like this, the chest wins easily.

The discount: later counts for less

A reward you get one step later counts as 90% of the same reward now. That 0.9 is the discount. Two steps later, 90% of 90%, and so on.

10 points…count as
now10
1 step later9
2 steps later8.1
5 steps later5.9

Why? Sooner is surer: the longer the walk, the more can go wrong. And without it, a game that never ends would add up forever.

With the discount at 0.9 the chest is still worth more (1.81 against 0.8). Turn it down past about 0.85 and the coin wins: the robot gets near-sighted and grabs what is close.

In code

def ret(rewards, gamma):
    return sum(r * gamma**t for t, r in enumerate(rewards))

coin  = [-1, 2]
chest = [-1, -1, -1, -1, -1, 10]

for gamma in (1, 0.9, 0.5):
    c, t = ret(coin, gamma), ret(chest, gamma)
    print(gamma, round(c, 2), round(t, 2), "chest" if t > c else "coin")

Same two routes as the room. At 1 and 0.9 the chest wins; at 0.5 the coin does.

The lesson: the return adds up what is still to come. The discount decides how far ahead the robot cares, and that can change what it chooses.
