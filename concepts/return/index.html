Lesson 3: Return

The return is all the reward still to come, with far-off reward counted for less by the discount.

    Rewards now count for more than rewards later

    One reward is not the goal. The agent wants all the reward that is still to come, added up. That total is the return.

    The return

    Look ahead along the path the agent will take and add up each reward it will collect. That sum is the return, and it is what the agent really tries to make big.

    The discount

    A reward far away is less certain than one right now, so it is counted for less. Each step further out multiplies the reward by the discount, a number from 0 to just under 1. At 1 nothing shrinks, at 0.5 every step halves it.

    The lesson: the return adds up the rewards still to come, and the discount sets how far ahead the agent looks. A small discount makes it near-sighted.
