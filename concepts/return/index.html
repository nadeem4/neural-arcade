Lesson 3: Return

The return is every reward still to come, added up. The discount makes rewards further away count less.

In this game: From the start there are two routes: a coin 2 steps away and a chest 6 steps away. Every step costs 1.

  1. In step 1, send the robot down each route and read its total.
  2. In step 2, watch the chest and the coin shrink in the room.
  3. In step 3, drag the discount down until the robot picks the coin.

What you saw

10 points…count as
now10
1 step later9
2 steps later8.1
5 steps later5.9
  • Add up each route. Coin: −1 + 2 = 1. Chest: −1 −1 −1 −1 −1 + 10 = 5. The robot takes the biggest return.
  • Later counts less. At a discount of 0.9, a reward one step later counts as 90% of the same reward now.
  • The discount can change the choice. At 0.9 the chest is still worth more (1.81 against 0.8). Turn it down past about 0.85 and the coin wins.

Key terms

TermIn this game
ReturnEvery reward still to come from where you are, added up. The past does not count.From the start: coin 1, chest 5.
DiscountHow much a reward one step later still counts. 0.9 means 90%.At 0.5 the near coin beats the far chest.

In code: the same idea in Python

 
def ret(rewards, gamma):
    return sum(r * gamma**t for t, r in enumerate(rewards))

coin  = [-1, 2]
chest = [-1, -1, -1, -1, -1, 10]

for gamma in (1, 0.9, 0.5):
    c, t = ret(coin, gamma), ret(chest, gamma)
    print(gamma, round(c, 2), round(t, 2), "chest" if t > c else "coin")

Same two routes as the room. At 1 and 0.9 the chest wins; at 0.5 the coin does.

The lesson: the return adds up what is still to come. The discount decides how far ahead the robot cares, and that can change what it chooses.
