Part 1 The problem

  1. 1 Agent and environmentThe agent is the learner that acts; the environment is everything it acts on, and it answers each move with a new situation and a reward. Up next
  2. 2 State, action, rewardA state is where things stand now, an action is a move the agent can make, and a reward is the number the world hands back for that move.
  3. 3 ReturnThe return is all the reward still to come, with far-off reward counted for less by the discount.
  4. 4 PolicyA policy is the agent's rulebook: in each state, which action to take.
  5. 5 ValueA state's value is how much reward the agent can expect from there on, if it keeps following its policy.
  6. 6 MDPAn MDP is the whole game written down: states, actions, rewards and where each move leads, where only the present state matters, not how you got there.
